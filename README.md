# As-Sabiqun 
## As-Sabiqun al-Awwalun | السابقون الأولون
A website dedicated to the story of the sahaba and some aspects of the life of the Prophet Muhammad ﷺ.

---

## 📖 About
This project presents the history of **As-Sabiqun al-Awwalun** — the first people who accepted Islam — alongside some of the biography (Seerah) of Prophet Muhammad ﷺ. The site aims to educate visitors on this foundational period of Islamic history through a visually engaging experience.

---

## ✨ Features
- Biographical profiles of the first seven converts to Islam
- Timeline of early Islamic history
- Short life story (Seerah) of Prophet Muhammad ﷺ
- Responsive design for mobile, tablet, and desktop
- Scroll-triggered animations for an engaging reading experience
- Icon-based navigation and visual elements

## 🎨 Animation Usage
This project uses **AOS (Animate On Scroll)** to trigger animations as the user scrolls. Example usage:

```html
<div data-aos="fade-up" data-aos-duration="800" data-aos-delay="200">
  <!-- content -->
</div>
```

```js
AOS.init();
```
